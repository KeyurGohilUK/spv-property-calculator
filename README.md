# SPV Property Calculator PWA

Upload all files to a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).

Open the HTTPS Pages URL in Safari on iPhone, then Share → Add to Home Screen → enable Open as Web App → Add.

The calculator works offline after its files are cached. Inputs are stored locally on the device. No backend, database or login is required.

Includes mortgage/ICR, higher-rate SDLT planning calculation, optional non-resident surcharge, purchase costs, refurbishment, annual cash flow, yields, cash-on-cash return, ICR PASS/FAIL, share, PDF and CSV export.

Tax rules can change and company SDLT treatment is fact-specific. Verify with a UK tax adviser/solicitor before relying on results.
