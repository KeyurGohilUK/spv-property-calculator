# Section totals UI update

This version adds a live amount to each financial section header on the Property Purchase Details page, so the value remains visible while the section is collapsed.

Header values:
- Purchase details: Purchase Price
- Stamp Duty Land Tax: SDLT
- Legal & survey costs: Legal + Survey total
- Mortgage costs: Arrangement + Broker + Valuation total
- Company costs: Company Formation + SPV Administration total
- Purchase costs: Land Registry/Searches + Insurance + Auction/Reservation + Additional Expenses total
- Refurbishment: Estimated Refurbishment Cost
- Purchase summary: Total Cash Required

No Supabase SQL or configuration changes are required.
