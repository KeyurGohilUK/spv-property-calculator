# Property compliance implementation

Property-specific, priority-driven BTL compliance is being developed in stages. The overview must rank verified overdue safety obligations and serious hazards above unknown checks, upcoming deadlines and long-valid certificates. Legal applicability must be determined per property and tenancy; unknown evidence must never be marked compliant.

Planned UI: Overview, Safety & Certificates, Tenancy & Legal, Maintenance & Records. Match the existing Company Compliance Hub using shared cream/brown design tokens in light and dark themes, with collapsible compliant items.

The initial implementation stage establishes rules and tests. It does not itself certify legal compliance, store evidence, or change production screens.
