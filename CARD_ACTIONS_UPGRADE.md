# Saved Property Card UI update

This UI-only update changes active saved-property cards:

- Removed the separate **Edit** button.
- Tap/click anywhere on a property card to open it in edit mode.
- Added keyboard support: focus the card and press **Enter** or **Space** to edit.
- Moved **Duplicate** and **Archive** actions to compact icons in the card's top-right corner.
- Added tooltips and accessible labels to both icons.
- No Supabase SQL or configuration changes are required.

PWA cache version: `v1.7.3-card-actions-icons`.
